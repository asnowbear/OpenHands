Action buttons keep their names, and drop the visible words

Visible action buttons whose label named a verb now show an icon from the existing set. The same i18n string is the accessible name and the tooltip. Confirmations, form submits, links, and controls whose text is the data stay written out.

1Action labels leave the face of the button

★ No Agent Server contract changes. minimumAgentServer stays put. The click handlers are the same functions; only the visible children of the button change. 38 files · +754 / −416.

The carrying example is GitControlBarPullButton. Before, the button painted an arrow and the word “Pull”. After, the arrow is the only visible child, and aria-label is t(COMMON$PULL).

ⓘ Dashed boxes are the old render. Solid boxes are the new render. The orange edge is the only behavioral move: the translated string is no longer a text node.

7Text that stays

⚠ These were left as words on purpose. A later pass should not “finish” them without a new decision.
  • Confirm / Cancel / Delete dialogs, including agent Continue and Cancel. The words are the decision.
  • Form submits such as Save, Rename, Create a plan, Start conversation, and Save and sync. The sentence is the explanation of that form.
  • Links, including BackNavButton with to and sidebar entries such as New Chat.
  • Text that is the content: repository and branch names, Code / Plan / Automate, the model and profile names, workspace mode, menu rows, Filters, and Group by status.
  • “Start new conversation with this skill” and “Read more” / “View more”. No single icon says that sentence.
  • Full-width “Check for updates”. Making it icon-only would restyle the update card, and the sentence is the action.

8Compatibility and risk

Glanceability is the risk. A folder and a puzzle on the home composer are smaller than “Open workspace” and “Plugins”. Hover and screen readers still get the old strings. Tests that looked up those buttons by visible text now look them up by accessible name, and the click assertions still call the same handlers.

Verified in the mock Canvas (npm run dev:mock on http://127.0.0.1:5173), not against a live Agent Server or LLM. Unit tests covering the converted buttons passed. No settings shape, conversation payload, or server endpoint changed.
